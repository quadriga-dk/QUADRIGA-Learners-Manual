# QUADRIGA Lernhinweise: Anleitungen und Empfehlungen für das Lernen mit QUADRIGA OER

[![DOI](https://zenodo.org/badge/1290879053.svg)](https://doi.org/10.5281/zenodo.21222824)

Dieses Repositorium enthält die **Lernhinweise** für die Nutzung von QUADRIGA-OERs. Sie richten sich an Lernende und erklären, wie eine OER im Browser gelesen, in der Cloud ausgeführt oder lokal auf dem eigenen Computer genutzt wird.

Die Lernhinweise sind **kein Template** und keine Anleitung zum Erstellen von OERs. Sie sind ein Nachschlagewerk für die Nutzung fertiger QUADRIGA-OERs.

## Inhalt

- **Ausführungsmodi:** Lesen, Cloud und lokal im Vergleich
- **Lesen (Book-Only):** die OER im Browser nutzen
- **Cloud-Ausführung:** Google Colab, Binder und JupyterHub
- **Lokale Ausführung:** Python-Umgebung einrichten und Notebooks starten
- **Assessment:** Quizze, Selbstkontrolle und Programmieraufgaben
