# Assessment nutzen

## Wozu dient das Assessment?

Das Assessment in QUADRIGA-OERs ist in erster Linie eine Lernhilfe. Es zeigt Ihnen, ob Sie ein Kapitel verstanden haben, wo noch Lücken sind und welche Inhalte Sie wiederholen sollten. Es dient nicht der Benotung durch eine Lehrperson.

Das Assessment begleitet Sie an drei Punkten:

- **Vor dem Lernen:** Es zeigt Ihnen, ob Sie die nötigen Vorkenntnisse mitbringen.
- **Während des Lernens:** Es gibt Ihnen Rückmeldung zu einzelnen Abschnitten und Lernzielen.
- **Am Ende:** Es hilft Ihnen einzuschätzen, ob Sie die Lernziele der OER erreicht haben.

## Formate

### Quizfragen

Single-Choice-, Multiple-Choice- und Exact-Match-Fragen werden automatisch ausgewertet. Sie erhalten unmittelbar Rückmeldung und in der Regel eine Erklärung, warum eine Antwort richtig oder falsch ist.

Bei Multiple-Choice-Fragen können mehrere Antworten richtig sein. Lesen Sie die Frage genau und wählen Sie alle zutreffenden Antworten.

### Reihungs- und Zuordnungsaufgaben

Bei diesen Aufgaben bringen Sie Elemente in die richtige Reihenfolge oder ordnen sie einander zu. Auch hier erhalten Sie eine Erklärung der richtigen Lösung.

### Aufgaben mit Selbstkontrolle

Bei komplexeren Aufgaben gibt es keine automatische Auswertung. Stattdessen erhalten Sie eine Musterlösung und/oder ein Bewertungsraster. Gehen Sie so vor:

1. Bearbeiten Sie die Aufgabe zunächst, ohne die Lösung einzublenden.
2. Vergleichen Sie Ihre Lösung anschließend mit der Musterlösung und dem Bewertungsraster.
3. Notieren Sie, was Sie gut umgesetzt haben und wo Lücken geblieben sind.
4. Wiederholen Sie die betreffenden Inhalte, wenn nötig.

Nehmen Sie sich für die Selbstkontrolle ausreichend Zeit. Die Aufgabe ist erst abgeschlossen, wenn Sie Ihre Lösung bewertet und die Konsequenzen für Ihr Weiterlernen gezogen haben.

### Testgetriebene Programmieraufgaben

Bei Programmieraufgaben können Tests prüfen, ob Ihre Funktion oder Pipeline das erwartete Ergebnis liefert. Gehen Sie so vor:

1. Lesen Sie die Aufgabenstellung und die vorgegebenen Tests.
2. Implementieren Sie Ihre Lösung.
3. Führen Sie die Tests aus.
4. Lesen Sie die Fehlermeldungen und verbessern Sie Ihre Lösung.
5. Wiederholen Sie den Zyklus, bis die Tests erfolgreich sind.

Die Tests sind Teil des Lernprozesses. Nutzen Sie die Fehlermeldungen, um Ihre Lösung gezielt zu verbessern.

## Assessment sinnvoll einsetzen

- **Ergebnisse ernst nehmen, aber nicht überbewerten:** Ein falsches Ergebnis zeigt, wo Sie noch lernen können – nicht, dass Sie das Thema nicht bewältigen.
- **Erklärungen lesen:** Die Begründung ist oft wichtiger als die richtige Antwort.
- **Mehrfach bearbeiten:** Sie können Aufgaben wiederholen, um Inhalte zu festigen.
- **Lücken dokumentieren:** Notieren Sie sich Themen, die Sie wiederholen möchten.
- **Nicht raten:** Wenn Sie eine Antwort nicht wissen, lesen Sie den betreffenden Abschnitt erneut, bevor Sie weitergehen.

## Generative KI

Standardmäßig ist die Nutzung generativer KI-Systeme für Assessments nicht vorgesehen. Wenn Sie KI-Unterstützung verwenden, obwohl sie nicht erlaubt ist, verlieren die Ergebnisse ihre Aussagekraft: Sie erhalten dann keine verlässliche Rückmeldung zu Ihrem Lernstand.

Wenn eine Aufgabe KI-Nutzung ausdrücklich erlaubt, halten Sie sich an die dort genannten Regeln. Geben Sie im Zweifel an, welche Unterstützung Sie verwendet haben.

## Datenschutz

- Geben Sie in Assessment-Aufgaben keine personenbezogenen oder vertraulichen Daten ein.
- Nutzen Sie für Aufgaben mit eigenen Daten die lokale Ausführung.
- Beachten Sie die Datenschutzregeln Ihres JupyterHubs oder Cloud-Dienstes.
