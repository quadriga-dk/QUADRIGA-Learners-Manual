# Lesen (Book-Only)

## Was bedeutet Lesen?

Im Lesemodus öffnen Sie die QUADRIGA-OER als Website im Browser. Sie benötigen weder Python noch Jupyter und müssen nichts installieren. Alle Inhalte, Abbildungen und Tabellen werden direkt dargestellt; ausführbarer Code wird nicht ausgeführt.

Der Lesemodus ist der einfachste Einstieg und eignet sich besonders für einen ersten Überblick, für theoretische Kapitel und zum Nachschlagen.

## So nutzen Sie den Lesemodus

1. **OER öffnen:** Rufen Sie die Web-Adresse der OER auf. Die Startseite führt in der Regel in das Thema und die Struktur ein.
2. **Navigation:** Nutzen Sie das Inhaltsverzeichnis in der Seitenleiste, um gezielt zu Kapiteln und Abschnitten zu springen.
3. **Suche:** Über das Suchfeld oben finden Sie Begriffe und Abschnitte innerhalb der OER.
4. **Launch-Buttons:** Ein Raketen-Symbol (🚀) kennzeichnet Kapitel, die Sie zusätzlich in der Cloud oder lokal ausführen können. Ein Klick auf den Button öffnet das Notebook im jeweiligen Dienst.
5. **Downloads:** Über die Symbole oben rechts können Sie einzelne Seiten als Markdown- oder PDF-Datei herunterladen, sofern die OER diese Funktion aktiviert hat.
6. **Externe Links:** Links zu anderen Websites öffnen in einem neuen Tab. Dort gelten die Bedingungen der jeweiligen Anbieter.

## Was Sie im Lesemodus tun können

- Kapitel vollständig lesen und durchsuchen
- Abbildungen, Tabellen und Formeln ansehen
- Lernziele, Hinweise und Zusammenfassungen nutzen
- Aufgaben lesen und Lösungen einblenden
- Assessment-Fragen beantworten, sofern sie ohne Code auskommen

## Grenzen des Lesemodus

- **Kein ausführbarer Code:** Notebook-Zellen werden nicht ausgeführt. Ergebnisse, die von Ihrer Eingabe abhängen, sehen Sie nur, wenn sie bereits im Buch gespeichert sind.
- **Keine eigenen Daten:** Sie können keine eigenen Datensätze in die OER einbinden.
- **Keine dauerhaften Änderungen:** Notizen und Bearbeitungen im Browser werden nicht in der OER gespeichert.

Wenn Sie Code ausprobieren oder eigene Daten verwenden möchten, wechseln Sie in die {ref}`Cloud-Ausführung<nutzung:modi:cloud>` oder die {ref}`lokale Ausführung<nutzung:modi:lokal>`.

## Barrierefreiheit

- Vergrößern Sie die Schrift mit der Zoom-Funktion Ihres Browsers.
- Abbildungen enthalten, soweit möglich, beschreibende Alt-Texte, die von Screenreadern vorgelesen werden.
- Die Navigation ist per Tastatur möglich.
- Wenn Ihnen Darstellungen oder Texte nicht zugänglich sind, nutzen Sie die Feedback-Möglichkeit am Ende der OER.

## Wann ist Lesen sinnvoll?

Der Lesemodus passt gut, wenn Sie:

- sich einen Überblick über die OER verschaffen möchten,
- Inhalte ohne technische Einrichtung lesen möchten,
- auf einem Gerät arbeiten, auf dem Python oder Jupyter nicht installiert werden kann,
- nur einzelne Abschnitte nachschlagen möchten.
